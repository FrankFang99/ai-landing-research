# WSO2 发布 Agent Manager，企业寻求应对日益严重的 AI Agent 泛滥问题

## 摘要

WSO2 发布 Agent Manager 产品，帮助企业解决 AI Agent 泛滥带来的安全、合规和管理问题。该产品提供 Agent 发现、身份管理、策略执行和流量监控等功能，使 IT 团队能够统一管理企业内部署的各种 AI Agent，并控制其行为和权限。
