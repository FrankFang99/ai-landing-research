DoorDash 采用多 Agent LLM 架构开发自动化系统，成功清理了积累多年的 6 万个 Feature Flag 技术债务。该系统通过多个 LLM Agent 协同工作，自动识别、分类和处理遗留代码配置，显著降低了工程维护成本。
