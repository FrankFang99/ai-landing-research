## 详细描述

同花顺是中国 **互联网券商** 的代表(2025 月活 3502 万,证券类 App 第一),其 AI 投顾路径不像 Wind 那样"重数据底座",而是走 **"自然语言交互 + MCP 数据接口 + 量化策略"** 的互联网路线。

### 第一阶段:i 问财 —— 自然语言选股的早期突破

同花顺很早就推出了 **i 问财**(iwencai.com)平台,用户通过自然语言提问(如"今天涨停的次新股有哪些"),AI 自动转化为选股策略。这是国内最早一批"自然语言 → 投资决策"的尝试。

### 第二阶段:2025-03 iFinD MCP + Skills —— 拥抱 AI Agent 生态

2025-03-30 同花顺在投资者互动平台披露:**iFinD 已推出面向金融数据服务的 MCP 工具、Skills 技能包**。

这是非常关键的战略动作 —— **MCP(Model Context Protocol)是 Anthropic 2024 年提出的开放协议**,让 AI Agent 能直接调用外部数据 / 工具。同花顺是国内首批把金融数据 MCP 化的厂商。

**具体能力**:
- 以 AI 数据获取为切入点,帮助模型降低幻觉
- 面向 Agent 场景提供更多金融能力:投研 / 风控 / 舆情检测等
- 未来可能面向量化回测 / 数据分析的金融数据接口命令生成能力,解决 AI-coding 场景的数据源问题

**已提供**:iFinD 上各类投研专用智能体,支持通过自然语言指令创建定制化智能体,基于预设指令定时 / 自动执行金融数据获取 / 分析 / 报告生成任务。

### 第三阶段:HIthinkGPT 自研大模型

同花顺自研 **HIthinkGPT** 大模型,根据雪球用户 2025 年横评:
- **风格**:一板一眼的教书先生 / 内容严谨 / 引用原文准确
- **优势**:资讯时效性较好 / 严谨性强 / 不胡编乱造
- **定位**:个人投资者 + 初级投研人员友好

### 第四阶段:2025-2026 量化平台 MindGo 升级

MindGo 是同花顺 2025 升级的量化平台:
- 支持高频回测
- 自然语言生成策略
- 接入 iFinD 全量数据
- 免费 + 收费分层

### 第五阶段:2026 iFinDClaw 对标 WindClaw

面对 Wind WindClaw 的发布,同花顺推出 **iFinDClaw**(对标 WindClaw 命名),定位"投研 AI 智能体平台",数据源为同花顺 iFinD 数据库,部署方式本地化 / 零配置。

### 同花顺的核心优势(差异化)

| 维度 | 同花顺优势 |
|---|---|
| **用户基础** | 3502 万月活(证券类 App 第一)/ 互联网原生用户认知度高 |
| **自然语言交互** | i 问财多年迭代,中文金融语义理解准确度高 |
| **交易效率** | 闪电交易系统 3 秒内委托 / Level-2 行情免费 |
| **量化工具** | MindGo 平台 + 自然语言生成策略 |
| **MCP 生态** | 2025-03 首批金融数据 MCP 化,抢 AI Agent 生态先机 |

### 不足(对比 Wind / 蚂蚁财富)

- **数据底座**弱于 Wind(机构客户认可度低,Wind 在公募 / 私募的份额仍占 90%+)
- **AI 深度**弱于蚂蚁(同花顺更偏"工具",蚂小财更偏"服务")
- **社区生态**弱于东方财富(同花顺没有股吧这种百万级日活的散户社区)

### 适合谁用

- **个人投资者 / 短线交易者**:3502 万月活 + 闪电交易 + Level-2 行情,核心场景是"快速选股 + 极速下单"
- **中小私募 / 量化团队**:MindGo 平台 + 自然语言策略 + iFinD 数据,性价比高
- **AI Agent 开发者**:iFinD MCP / Skills 工具包,直接接入 AI Coding 工作流
