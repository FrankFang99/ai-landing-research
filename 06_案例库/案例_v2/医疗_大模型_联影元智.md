## 详细描述

联影集团 2025-04-09 在 CMEF 同期举办的 **uAInnovation 2025 创新大会** 上,重磅发布「元智」医疗大模型(uAI NEXUS)+ 同步推出覆盖影像诊断、临床治疗、医学科教、医院管理、患者服务 **5 大场景的 10+ 医疗智能体**。这场发布标志着医疗 AI 从"单点工具"进入"多智能体集群"时代。

### 元智大模型:多模态医疗大模型底座

**多模态架构**:
- **元智文本大模型**:接入 DeepSeek 后,长文本 + 复杂推理能力大幅提升,模型体积仅原始 1/4(便于医院本地化)
- **元智语音大模型**:医疗术语精准识别 + 智能声纹分析 / 支持多人同时对话身份识别
- **元智视觉大模型**:医疗视觉任务(4D 建模 / 高速电影级渲染 / 器官组织分割)
- **元智影像大模型**:数千万级影像数据 + 数十万级精细标注 / 10+ 影像模态 / 300 种影像处理任务 / 准确率 **>95%**
- **医疗混合多模态大模型**:看、听、读、想无缝衔接的临床工作流

**王维(联影集团董事长)判断**:"大模型的竞争已经从单纯的'参数竞赛',逐渐转向围绕'生态协同和场景落地'的下半场比拼。"

### 10+ 医疗智能体(多智能体集群)

#### 1. uMetaImaging 影像全智能体(全院级影像大脑)

**突破**:打破传统 AI"单病种、单应用"局限 —— **一次胸部 CT 扫描自动检出 37 种病种**(胸腔 / 食管 / 纵隔 / 气管与支气管 / 肺部 / 骨骼 / 心脏与大血管)

**数据指标**:
- 平均 **AUC 0.92**(行业 SOTA 0.76,**+10pp+**)
- 阅片时间 **-50%**
- 改变传统阅片工作流(语音操控"诊断报告智能书写")

#### 2. uAI MERITS 多元手术智能体(智慧手术室)

**眼 / 脑 / 手协同**:
- **uAI Avatar(智能大脑)**:通过医生语音指令实时操控手术设备与机械臂
- **uAI Vision(智慧之眼)**:精准空间定位 / 实时感知手术器械位置
- **智能手**:高精度机械臂实现自适应器械传递

#### 4. uMetaGenesis 设备管理智能体

**能力**:设备全生命周期管理 / 故障提前预测

### 联影的差异化:"硬件 + 软件 + 临床"全栈协同

联影的 AI 战略不是单点模型,而是**"医疗装备 + AI 大模型 + 多智能体"全栈协同**:
- **硬件底座**:CT / MR / PET-CT / DSA / 直线加速器 等全谱医疗装备
- **AI 底座**:元智大模型 + 多模态能力 + DeepSeek 长文本
- **智能体集群**:5 大场景 10+ 智能体
- **临床落地**:复旦中山 / 中山肿瘤 / 河南省人民医院 / 北京协和等头部三甲

这种"装备 + AI + 临床"一体化,是联影 10+ 年深耕医疗装备的天然护城河 —— 其他 AI 公司(包括京东健康 / 推想 / 数坤)没有装备底座,只能做软件层。

### 行业意义:医疗 AI 从"单点工具"到"多智能体集群"

**uAInnovation 2025 的发布标志着 3 个转变**:
1. **从单点工具到多智能体集群** —— 影像 / 治疗 / 科教 / 管理 / 服务 全场景覆盖
2. **从参数竞赛到生态协同** —— 大模型要"用起来"才算赢
3. **从中心三甲到基层下沉** —— 4 倍小体积便于基层本地化部署
