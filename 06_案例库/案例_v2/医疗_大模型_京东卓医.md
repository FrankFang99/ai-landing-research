## 详细描述

京东健康 2025-01 在 **2025 京东健康年度医生盛典** 上,首次发布医疗大模型产品体系 **"AI 京医"** + 业内第一个面向医院全场景应用的大模型产品 **"京东卓医(JOY DOC)"**。这是国内首个 **"互联网医疗 + 大模型 + 数字医生 + 医院全场景"** 的完整产品矩阵。

### 第一阶段(2023-07):京医千询首发

2023-07-13 京东健康发布 **京医千询** 医疗大模型(基于京东言犀通用大模型),同步推出医疗健康开放生态平台 **"京医星脉"**。

### 第二阶段(2025-01):AI 京医 + 京东卓医双发布

#### 「AI 京医」产品体系(3 大产品)

**1. AI 诊疗助手 2.0**:
- **分诊准确率 99.5%**
- **电子病历效率 +120%**
- **AI 一次问题解决率 90%+**
- 2024 年初 1.0 上线即成为医生群体使用率最高智能辅诊平台

**2. AI 科研助手**:
- 收录 **超 1000 万国内外专业文献**
- 支持医学论文一键输出
- 所有功能均免费向医生开放

**3. AI 医生智能体**(数字医生):
- 2025-02-14 正式上线
- 7×24 解答患者问题 / 疾病科普 / 病程管理 / 用药提醒
- 接入 DeepSeek 优化算法

#### 「京东卓医(JOY DOC)」医院全场景大模型(3 大模块)

**1. 个人就医管家**:
- 诊前:智能分诊 / AI 问诊 / 匹配科室与医生
- 诊中:全景展示签到 / 排队 / 缴费 / 检查 / 取药 / 实时智能调度
- 诊后:就诊清单 / 用药咨询 / 健康档案

**2. 医生数字分身**:
- **病历书写效率 +120%**
- **AI 一次问题解决率 90%+**
- 半托管式自动驾驶级智能医患沟通 / 7×24 解答患者追问

**3. 未来数字医院**:
- 医院"超级大脑"
- 线上线下闭环 / 互联网医院 2.0 / 智能引导 / 资源调度

### 第三阶段(2025-02-28):京医千询全面开源

2025-02-27/28 京东健康宣布 **"京医千询"医疗大模型启动全面开源** —— 所有模型参数、数据构造、多阶段模型训练、模型评测等核心代码都公开。

**这是国内医疗行业首个全面开源的垂类大模型**。

**京东健康探索研究院首席科学家王国鑫**:"AI 医疗最大挑战是数据'量质双缺'。"

### 第四阶段(2025-04):宿迁率先落地

2025-04-03 江苏宿迁宿豫区数据局宣布:**宿豫医院率先落地应用京东卓医**,通过"个人就医管家 / 医生数字分身 / 未来数字医院" 三大模块,让市民看病更舒心、医生科研更高效、医院运营更轻松。

**应用创新**:
- 诊前数字医生多轮多模态交互问诊
- 到院一站式服务(签到 / 排队 / 缴费 / 检查 / 取药)
- "服务找人" 主动医疗理念

### 第五阶段(2026-01):1500+ 专家医生智能体

2026-01-17 2026 京东健康年度医生盛典披露:**"AI 京医"体系已上线超 1500 个专家医生智能体**,京东卓医已在多家医院落地。
